# 差异化

小说推广短剧必须和原文有可见的区别，但不能改掉原文的主线因果和关键事实。具体手法、可改与不可改的范围见 short_drama_craft 的第三、五节。

方案层写：观众熟悉的版本是什么、本改编保留的原文核心、整体上做了哪些可见的变化。分集层每集写一到三处具体改动，格式“原文 → 改编 → 强化了什么冲突”。

例：常见开锁后角色感恩，当前角色依然负忠诚度，形成主角预期与现实的反差；随后用行为体现，不重复系统解释。

例：原文反派私下威胁 → 改为当众逼问并限三十秒答复 → 加入旁观者和时限，压迫和之后的反击都有观众。

与原文对白重合是差异化信号，不能单凭重合比例宣称原创、合规或失败。
