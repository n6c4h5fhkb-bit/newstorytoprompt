# M0 真实验证记录（待用户填写）

可用片段的定义：用户愿意保留并剪入成片，无需重做该生成。微调后期文字、替换配乐不算重做；为纠正人物、动作、声音或连续性重新生成算 redo。

选择同一 U01/U02 场景，相同模型、账号设置和参考素材。旧模板和新模板每个提示词各生成三次，记录每次是否保留、原因、真实时长、台词字数和说话用时。平台不会接收这些媒体。

旧模板使用用户目前实际采用的版本，保留原文或版本标识；新模板也记录版本。场景、模型、账号设置和参考素材的差异一并注明，方便检查比较是否成立。

旧模板所有试次保留数 / 试次总数是 pre-platform baseline。新模板必须更高才通过 M0。实测说话字数 / 实测说话秒数用来调整 config 的 speech_rate_chars_per_sec；实测一集时长用于校准 3–5 分钟估算。

M1 的首次生成可用率由该集逐单元的首次反馈计算，与这个基线比较。没有反馈的单元显示未测，不能计入成功分母；后续重做成功不能改写首次反馈。

若 M1 不优于基线，停止扩展后续里程碑，先检查剧本、资产描述、提示词或模型能力。重构审查没有预测 redo 的失败时，记录差异并重新评估其导出门槛。
